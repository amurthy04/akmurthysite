# Akshay Murthy

A deliberately minimal static blog. The homepage mirrors the reference website's Helvetica typography, right-aligned 150px column, blue links, and 30px/20px menu margins.

Sample posts are in `posts.json`. Replace their titles, ISO dates, and paragraph arrays, then run `node generate.mjs` to regenerate the static pages in `dist`. Posts are sorted newest first. Each post has its own shareable URL. The persistent sidebar shows a 15-row (240px) scrolling window. An entry marked `"fixed": true` in `posts.json` is pinned directly below the name and never scrolls; every other entry scrolls. `About` is pinned by default. The active post link is bold, and posts have no visible heading. A post may carry an optional `image` object (`src`, `alt`, `width`, `height`) rendered above its prose; `*asterisks*` in a paragraph become italics. Discrete row stepping supports touch, trackpad, wheel, and keyboard navigation. Pointer travel maps one to one onto the list: every row height of movement steps exactly one row, and sub-row travel is banked rather than dropped, so a slow drag and a fast flick cover the same distance. Each step immediately updates the date and aligns a complete essay row with it; there is no continuous scrolling or delayed settling. A row-and-a-half mask ramp at each edge is deeper than one step, so links ease in and out across several rows instead of appearing at full strength. Post navigation preserves the sidebar and its scroll position. Dates appear only while the link window scrolls and fade after 600ms of inactivity. Reduced-motion preferences disable movement.

Serve `dist` with any static HTTP server. No packages are required.
